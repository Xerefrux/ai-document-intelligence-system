# API reference

Generated by `scripts/gen_docs.py` from the running application. The same information, with request and response schemas and a way to try each call, is served at `/api/docs` while the server runs.

## Conventions

- Everything is under `/api`. Timestamps are UTC, ISO 8601 with a trailing `Z`.
- Authentication: when `DOCINTEL_API_KEY` is set, send it as `X-API-Key: <key>` or `Authorization: Bearer <key>`. `/api/health` stays public.
- Errors always have this shape, with a stable `code` for programs and a `message` written for people: `{"error": {"code": "VERSION_CONFLICT", "message": "...", "details": {}}}`.
- Lists take `limit` and `offset` and return `{items, total, limit, offset}`.
- Editing a record takes an optional `expected_version`. If someone else saved first the answer is `409 VERSION_CONFLICT` instead of a silent overwrite.
- Reprocessing a document that has manual corrections answers `409 CORRECTIONS_WOULD_BE_LOST` unless the request says `confirm: true`.
- Too many requests from one client answer `429 RATE_LIMITED` with a `Retry-After` header.

## Endpoints

| Method | Path | What it does |
|---|---|---|
| GET | `/api/config` | Settings that are safe to show (keys are never included) |
| GET | `/api/documents` | List documents |
| POST | `/api/documents` | Upload one or more files |
| POST | `/api/documents/reprocess-failed` | Queue every failed document again |
| GET | `/api/documents/{doc_id}` | One document with its records, issues and processing history |
| DELETE | `/api/documents/{doc_id}` | Delete a document, its records and its stored file |
| POST | `/api/documents/{doc_id}/cancel` | Stop a queued or running document |
| GET | `/api/documents/{doc_id}/file` | Download the original file |
| GET | `/api/documents/{doc_id}/pages/{page_no}/image` | PNG picture of one page |
| POST | `/api/documents/{doc_id}/records` | Add an empty record by hand (for a document where nothing was detected) |
| POST | `/api/documents/{doc_id}/reprocess` | Process a document again (failed jobs, or after a settings change) |
| GET | `/api/documents/{doc_id}/text` | Extracted text, a window of pages at a time |
| GET | `/api/export/records` | Download records as CSV or JSON |
| GET | `/api/health` | Is the service up? |
| GET | `/api/issues` | Validation issues across all documents (the review queue) |
| GET | `/api/jobs` | Background jobs |
| GET | `/api/reconciliations` | Earlier comparisons |
| POST | `/api/reconciliations` | Compare invoices against a spreadsheet (or any two sets of documents) |
| GET | `/api/reconciliations/{rec_id}` | One comparison with every pair |
| GET | `/api/records` | List records, with the same filters as search |
| GET | `/api/records/{rec_id}` | One record with every field, its evidence, line items, issues and edit history |
| PATCH | `/api/records/{rec_id}` | Correct values |
| DELETE | `/api/records/{rec_id}` | Delete a record that should not exist (for example a false detection) |
| POST | `/api/records/{rec_id}/approve` | Mark a record as checked by a person |
| POST | `/api/records/{rec_id}/revalidate` | Run the validation rules again |
| GET | `/api/search` | Search documents |
| GET | `/api/stats` | Counts, success rate, processing time and queue state |
